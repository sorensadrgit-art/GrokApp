## still

**/still**

Direct one still: subject, light, and what must stay recognizable.

Group: `picture`

When: You want a single image direction, not a menu of moods.

Steps:

1. Name the subject.
2. Name the light and the lens feel.
3. Say what must not change.

Do not: Don't add people, logos, or text you weren't given.

Example: Still of the product on a wood table, north window, no extra props.
## contact

**/contact**

Four distinct directions for the same subject, labeled, so one can be picked.

Group: `picture`

When: You haven't chosen a direction yet.

Steps:

1. Four directions.
2. Label each.
3. Same subject in all four.
4. Say how they differ in one line.

Do not: Don't produce four near-duplicates.

Example: Contact sheet for a clinic hero. Same room, four lights.
## edit-img

**/edit-img**

Change only what is specified in the uploaded image.

Group: `picture`

When: An image exists and should be edited, not restaged.

Steps:

1. List the edits.
2. Leave everything else.
3. If an edit would require inventing a fact, skip it and say so.

Do not: Don't change identity, pose, or background unless the instruction says so.

Example: Edit-img: remove the outlet on the back wall. Leave the person alone.
## clip

**/clip**

Direct one clip: start, action, end, camera. One motion.

Group: `picture`

When: You want a short moving shot.

Steps:

1. Start frame.
2. The action.
3. End frame.
4. Camera move, if any.

Do not: Don't stack three ideas in one clip.

Example: Clip: the goniometer settles on the joint. One slow push-in. No text.
## hero

**/hero**

A clean hero image with the subject as the focal point.

Group: `picture`

When: You need a primary picture for a page or a card.

Steps:

1. Subject dominates.
2. Background stays quiet.
3. Leave clean space only if a line of type was provided.

Do not: Don't add a headline you weren't given. Don't crowd the subject.

Example: Hero of the instrument on a dark field. No slogan.
## ugc

**/ugc**

A user-style photo or clip, as if someone is showing it to a friend.

Group: `picture`

When: You want it to feel handheld, not like an ad.

Steps:

1. Handheld.
2. A real place.
3. Imperfect framing.
4. The product still readable.

Do not: Don't polish it into a studio shot.

Example: Ugc of the product on a kitchen counter, phone photo.
## labels

**/labels**

Use only the labels and facts provided. Leave off anything else.

Group: `picture`

When: The image needs words and the words must be true.

Steps:

1. Use the supplied labels verbatim.
2. If a label wasn't supplied, don't add one.
3. Keep them short.

Do not: Don't invent measurements, prices, or anatomy.

Example: Labels: only 'Knee flexion' and '120°'. Nothing else.
## codes

**/codes**

Treat pasted picture-book tokens as shorthand. Follow each meaning.

Group: `picture`

When: You are combining visual codes from the other book.

Steps:

1. Read each code's meaning.
2. Apply them together.
3. Keep the subject recognizable.
4. If a code wants a fact you don't have, omit it.

Do not: They are not secret switches. Don't obey the token if you ignore the meaning.

Example: Codes: /packshot and /northlight. Subject is the bottle I uploaded.
